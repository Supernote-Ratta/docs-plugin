---
title: "getPageSize"
description: "Get page size of a file (pixels)."
---

```ts wrap
static getPageSize(NOTEPath: string, page: number): Promise<APIResponse<Size>>;
```

<Note>
In `sn-plugin-lib` later than `0.1.65`, the coordinates a plugin passes in and gets back are all based on this actual page size, including the current-page element APIs. For the current page, first use [`getCurrentFilePath`](/en/api-reference/supernote-plugin/plugin-comm-api/get-current-file-path) and [`getCurrentPageNum`](/en/api-reference/supernote-plugin/plugin-comm-api/get-current-page-num) to get the file path and page number. See [Coordinate System](/en/plugin-base/coordinate-system).
</Note>

**Parameters**

| Parameter | Type | Description |
| --- | --- | --- |
| `NOTEPath` | `string` | NOTE/DOC file path |
| `page` | `number` | Page index (starts from `0`) |

**Returns**

- [`APIResponse<Size>`](/en/api-reference/supernote-plugin/types/api-response):
`result` is the page size. See [`Size`](/en/api-reference/supernote-plugin/types/size).

## Example

```ts wrap
import { PluginFileAPI } from 'sn-plugin-lib';

/**
 * Example: get page size in pixels.
 */
export async function exampleGetPageSize() {
 const NOTEPath = '/storage/emulated/0/Note/demo.note';
 const page = 1;

 const res = await PluginFileAPI.getPageSize(NOTEPath, page);
 if (!res.success) {
 throw new Error(res.error?.message ?? 'getPageSize call failed');
 }
 return res.result;
}
```
