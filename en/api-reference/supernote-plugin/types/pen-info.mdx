---
title: "PenInfo"
description: "Pen information."
---

| Field | Type | Description |
| --- | --- | --- |
| `type` | `number` | Pen type: `10` fineliner, `16` pressure pen, `11` marker, `15` calligraphy |
| `color` | `number` | Pen color value: `0` (`0x00`) black, `157` (`0x9D`) dark gray, `201` (`0xC9`) light gray, `254` (`0xFE`) white |
| `width` | `number` | Pen width (minimum `100`) |
