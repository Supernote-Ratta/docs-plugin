---
title: "recycleElement"
description: "Recycle an Element object and release native Android cache on the native side."
---

This API only releases the cache for the single Element identified by `uuid`, without affecting other elements. Compared to [`clearElementCache`](/en/api-reference/supernote-plugin/plugin-comm-api/clear-trail-cache), which clears the entire cache, this is the recommended way to release an element promptly once you're done with it.

```ts
static recycleElement(uuid: string): void;
```

**Parameters**

| Parameter | Type | Description |
| --- | --- | --- |
| `uuid` | `string` | Element unique identifier (see [`Element.uuid`](/en/api-reference/supernote-plugin/types/trail)) |

## Example

```ts wrap
import { PluginCommAPI } from 'sn-plugin-lib';

/**
 * Recycle Element example.
 */
export async function exampleRecycleElement(uuid: string) {
 PluginCommAPI.recycleElement(uuid);
}
```
