---
title: "duplicateFlipLassoElements"
description: "Duplicate elements in the current lasso selection and flip the duplicated elements."
---
<Note>
You must create a lasso selection before calling this API; otherwise the call fails.
</Note>

```ts
static duplicateFlipLassoElements(flipType: number): Promise<APIResponse<boolean>>;
```

**Parameters**

| Parameter | Type | Description |
| --- | --- | --- |
| `flipType` | `number` | Flip type. Only `1` and `2` are supported. `1` means horizontal flip, and `2` means vertical flip |

**Notes**

- This API duplicates supported elements in the current lasso selection, then flips the newly created elements
- The original elements remain unchanged and are not flipped in place
- Only strokes and geometries participate in duplicate-and-flip; other element types are ignored
- Only horizontal and vertical flipping are currently supported

**Returns**

- [`APIResponse<boolean>`](/en/api-reference/supernote-plugin/types/api-response):
`result === true` indicates the duplicate-and-flip operation succeeded

## Example

```ts wrap
import { PluginCommAPI } from 'sn-plugin-lib';

/**
 * Duplicate supported elements in the current lasso selection and flip them horizontally or vertically.
 */
export async function exampleDuplicateFlipLassoElements(flipType: 1 | 2) {
 console.log('duplicateFlipLassoElements flipType:', flipType);
 const res = await PluginCommAPI.duplicateFlipLassoElements(flipType);
 if (!res.success) {
 throw new Error(res.error?.message ?? 'duplicateFlipLassoElements call failed');
 }
 console.log('duplicateFlipLassoElements result:', res.result);
 return res.result;
}
```
